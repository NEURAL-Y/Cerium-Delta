# Changelog

All notable changes to **Cerium Delta** will be documented in this file.

## [1.0.0] - 2026-08-21

### Added

* Initial stable release of **Cerium Delta**.
* Neural observability tools for analyzing neural network behavior.
* **Layer Contribution Score (LCS)** for evaluating parameter contribution.
* **Sensitivity analysis** for monitoring parameter responsiveness.
* **Evolution analysis** for tracking parameter changes over time.
* Support for analyzing both **weights and biases**.
* Core infrastructure for processing and connecting neural network metrics.
* Foundation for future visualization and observability features.

### Notes

This release establishes the core foundation of Cerium Delta. Future versions will expand visualization capabilities, metric relationships, and large-scale parameter analysis.
